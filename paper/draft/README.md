# Section drafts

One Markdown file per paper section, named by its number in [../outline.md](../outline.md),
e.g. `03-data.md`, `04-method-har.md`, `05-results-har.md`.

- Draft a section at the end of the roadmap phase that produces its results (see the
  **Paper** column in [ROADMAP.md](../../ROADMAP.md)).
- Only use numbers listed in [../claims.md](../claims.md), and put the claim ID next to the number
  in a comment while drafting, e.g. `92.92 <!-- C4e -->`, so numbers can be re-checked before submission.
- Update the section's status in `outline.md` when a draft lands.
